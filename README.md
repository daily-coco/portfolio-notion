# 포트폴리오 - Notion API 활용

Notion API를 연동해 프로젝트 데이터를 관리하는 개인 포트폴리오입니다.

이 프로젝트는 퍼블리셔 경험을 바탕으로 React + TypeScript 기반 프론트엔드 구조를 이해하고 확장하기 위해 제작했습니다.  
구현 과정에서는 AI를 보조 도구로 활용하여 코드 구조 설계, 기능 구현 방향 검토, 오류 해결, 문서 정리를 진행했습니다.

단순히 결과물을 만드는 것보다, AI가 제안한 코드를 그대로 사용하는 데 그치지 않고  
구조와 흐름을 이해하고 수정하며 실제 배포 가능한 형태로 완성하는 데 초점을 두었습니다.

## 배포 링크

https://portfolio-notion-vert.vercel.app/

## 프로젝트 소개

이 프로젝트는 Notion API를 활용해 Notion을 CMS처럼 사용하고,  
콘텐츠 관리와 화면 구현을 분리하는 방식으로 만든 포트폴리오입니다.

프로젝트 목록과 상세 콘텐츠를 Notion 데이터베이스 기반으로 관리하고,  
프론트엔드에서는 이를 조회해 사용자에게 보여주는 구조로 구성했습니다.

퍼블리셔로서 익숙한 화면 구현 경험을 바탕으로,  
React 환경에서 데이터 흐름, 상태 처리, API 연동, 컴포넌트 구조화를 경험하기 위해 제작했습니다.

## AI 활용 방식

이 포트폴리오는 AI 보조를 활용해 제작한 프로젝트입니다.

AI는 주로 다음과 같은 부분에서 보조 도구로 활용했습니다.

- React + TypeScript 기반 코드 구조 설계 보조
- Notion API 연동 방식 검토
- 컴포넌트 분리 방향 제안
- 로딩 / 에러 / 빈 상태 처리 방식 정리
- 배포 환경에서 발생한 오류 원인 파악
- README 및 프로젝트 설명 문서 정리

다만 AI가 생성한 결과를 그대로 사용하는 것이 아니라,  
프로젝트 목적에 맞는지 확인하고 수정하며 구조와 동작 방식을 이해하는 과정을 거쳤습니다.

## 작업 목표

- 퍼블리셔 경험 위에 React 기반 프론트엔드 작업 방식을 확장해보기
- 정적 하드코딩이 아닌 데이터 기반 포트폴리오 구조 만들기
- Notion API를 활용해 콘텐츠 관리와 화면 구현을 분리해보기
- 실제 배포 환경에서 API, 환경변수, 빌드 이슈를 점검해보기
- AI 보조를 활용하되 코드 흐름과 구현 의도를 이해하며 완성해보기
- 사용자 입장에서 자연스러운 탐색 흐름과 읽기 경험 만들기

## 기술 스택

### Frontend

- React
- TypeScript
- Vite

### Styling / UI

- Vanilla-extract

### Data / State

- TanStack Query
- Notion API

### Deploy

- Vercel
- Serverless Function (`/api`)

## 주요 기능

- Notion 데이터베이스 기반 프로젝트 목록 조회
- slug 기반 프로젝트 상세 페이지 조회
- 프로젝트 상세 본문 렌더링
- 로딩 / 에러 / 빈 상태 UI 분기
- 이전글 / 다음글 탐색
- 배포 환경 기준 환경변수 분리
- 서버리스 API를 통한 Notion 데이터 가공 및 전달
